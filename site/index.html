How it works

  1. Point it at the CLIs you already own. It detects your installed tools and reads their existing logins. No new accounts, no resold API keys, no per-seat fee.
  2. Describe the job. It rates difficulty, checks live plan usage, and picks the cheapest capable model. If one refuses or fails, it moves to the next.
  3. Get the result and the receipt. The work lands with a cost line — model, steps, tokens.

Features

  • Free-first routing. Configured free APIs and local models get first attempt at every difficulty; paid plans are fallbacks.
  • Live usage meters. See plan quota before you start, not after you are throttled — including a real meter for the Command Code plan.
  • The Hive floor. Give each AI a seat. They read a shared room, you dispatch from the dashboard or your phone, and a wake message brings the right seat back.
  • Escalation. A call that nobody answers is paged through the roster, then to your phone — it does not vanish.
  • Bounded jobs. A restart limit stops a run that is failing in bursts instead of riding it to the step cap.
  • Runs where you do. Windows today; CI on Windows and Linux.

Honest limitations

  • You need at least one installed AI CLI and a paid plan (or a free API key) to get value.
  • Grok is left out of edit mode on Windows today.
  • The dashboard is local by default; remote access needs Tailscale.
  • It is a bench, not magic: routing saves money, it does not make a bad prompt good.

FAQ

Do I need an API key? No. If you already run Claude Code, Codex, Grok or the Antigravity CLI, Mega Zword uses those logins. Free API keys (OpenRouter, Groq) are optional extras.

Does this replace my subscriptions? No — it makes them work together. Keep the plans you use; it routes and coordinates them.

Is it open source? No. Mega Zword is proprietary software; your license covers the app and its updates. Nothing of yours leaves your machine except the prompts you send to the AIs you already pay for.

What runs on your servers? Nothing by default. Routing, logs and project memory stay on your machine. The optional cloud room is a free Cloudflare Worker you can self-deploy.
