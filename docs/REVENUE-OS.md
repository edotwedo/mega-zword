# Revenue OS (Lumen-20 owns, 2026-10-19)

First principles: **money is someone paying for an outcome they value more than the
price.** Nothing else counts.

POSIWID (purpose of the system is what it does): judge this project by what it
**produces** — dollars collected, calls booked, deliverables shipped. Not by how
clever the tool is. Today it produces a lab. This file is how we change that.

Constraints: COGS is ~zero (local + free tiers), so revenue is nearly pure margin.
The scarce input is Phil's attention, so every offer must be repeatable and
bot-deliverable.

## Three offers (cash first)

| Offer | Price | Who | Deliverable | Why it sells |
| --- | --- | --- | --- | --- |
| **AI Bench Setup** | **$249** | Solo devs/agencies with 2+ AI subscriptions | Working bench + one-page cheat sheet + short recording | Done in 60-90 min; immediate relief from tab-copying and quota surprises |
| **AI Spend Audit** | **$149** | Anyone paying for multiple AI tools | 3-5 page report: where quota leaks, what to route where, projected savings | Cheap entry offer; leads naturally to Setup |
| **Automation Sprint** | **$750-1,500** | Small businesses/creators | One workflow automated end-to-end, with tests, docs, and 2 weeks of support | Highest ticket; uses the same engine |

## Delivery pipeline (bot-assisted, repeatable)

1. **Intake** — short form: tools, subscriptions, pains, budget.
2. **Diagnostic** — `megazword doctor` + a sanitized environment report (no keys).
3. **Proposal** — generated from a template; Quill-21 drafts, Lumen-20 reviews.
4. **Delivery** — Lumen-20/Phil run the session; the bot records the steps.
5. **Artifacts** — config, report, recording, cheat sheet (all templated).
6. **Follow-up** — testimonial request + the optional $15/mo support offer.

## Lead engine

- **Channels, in order of speed:** warm network → X/LinkedIn → r/selfhosted,
  r/LocalLLaMA (follow the rules) → Upwork/Fiverr → referrals.
- **Volume:** 20 personalized messages/day, target 5 calls/week.
- **Script (one line):** "You're paying for 3 AI subscriptions. I'll set them up to
  route by cost and prove the savings in a short report. $249, 90 minutes."
- **Rule:** no dollar this week = change the offer or the channel, not the tool.

## Product (weeks, funded by services)

- Founding lifetime **$49** (first 50) → Pro **$99**; optional **$15/mo** support.
- Gate: signed installer + 5-minute onboarding + one demo video.
- Never let product work starve the cash work; services pays for product.

## Metrics (POSIWID, weekly)

| Stage | Target |
| --- | --- |
| Messages sent | 100 |
| Replies | 10 |
| Calls booked | 3 |
| Offers sent | 3 |
| Sales | 1-2 |
| Dollars collected | $500-1,500 |

Track these in the room every Friday. If a number is zero for two weeks, that
stage is the bottleneck — fix that stage, not the product.

## Guardrails

- No custom contracts below $150.
- No free 1:1 support before 20 licenses.
- Keep infrastructure at $0 (local + free tiers).
- Every deliverable is templated and reusable; bespoke work is the exception.
- Keep costs flat as income rises: the long game is giving the work away from a
  position of stability, not selling it forever.
