# Mega Zword

One terminal tool that runs all your AI coding CLIs (Claude Code, Codex, Grok,
Gemini) and picks the right model for each task. It mixes in free models to
save paid usage, tracks usage against each plan's reset, and moves work up to
a stronger model when a cheaper one fails.

**Status:** early development, nothing usable yet. See `docs/STATUS.md`.
